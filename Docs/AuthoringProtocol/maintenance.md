# 维护约定与验收

状态：本轮MCP方案草案。维护入口为本目录README.md，具体数据契约为protocol.md。其他业务插件的相互依赖及Fab发布策略暂不调整。

## 所有权

| 内容 | 唯一维护位置/职责 |
|---|---|
| 源码Actor、稳定标记、协议schema、通用配置命令 | MassBattleEditorMCP / ActorToMassbattleUnitEditor |
| 主色分析、TeamMask、共用材质颜色绑定 | MCP原生TeamColor实现 |
| 特效挂点配置、Burst/Attached声明与验证 | MCP Bindings，复用现有Effect MCP |
| 炮塔编辑器适配器 | MCP侧可选集成，调用炮塔公开编辑器库 |
| 炮塔姿态、后坐、开火状态 | MassBattleSingleTurret现有运行时 |
| 投射物、批量特效执行与帧同步 | 对应既有MassBattle运行时，不迁入MCP |
| 用户源文件 | Content/ActorToMassBattleUnitEditor/UnitSources；升级不覆盖 |
| 生成游戏资产 | 用户指定输出目录，资产引用追踪归属 |

## 新增一项功能时

1. 先记录已有公共入口及当前字段，确认不能直接通过已有schema表达后再扩展。
2. 定义稳定capabilityId、schemaVersion、参数schema、可用性、输出和missingPolicy。
3. 提供者只做参数映射和既有API调用；GUI与MCP复用同一校验/导出实现。
4. 注册写入归属：不得覆盖别的提供者或用户维护的玩法字段。
5. 增加有插件/无插件/再次移除三组样例和回归；不存在有效基础降级时明确说明。
6. 更新本目录能力表、下载/文档链接与支持矩阵。无公开下载地址时明确“未发布”，不制造链接。

## 版本与历史配置

协议主版本不兼容时拒绝执行，但配置可读取保留；次版本新增可选字段须给默认行为。扩展payload有独立schema版本。迁移函数由字段所有者提供，迁移不默默重写未知字段。

SourceActor的revision与导出报告绑定；报告记录MCP版本、提供者版本、引擎版本、框架commit、输入内容hash、启用/降级功能、写入资产和错误。部分写入失败不能记录为完整成功。

现有Actor转换UCLASS、MCP入口及资产不能直接改模块路径或删除。整理实现时保留旧入口转发和单独资产迁移说明。旧Python配置逐步由原生入口替代，回归样例保留，但不让新旧脚本同时维护生产配置。

## 第一批验收样例

| 样例 | 通过条件 |
|---|---|
| 只有基础MassBattle+MCP | 可保存源码Actor、生成普通单位与队伍色 |
| 安装炮塔插件 | 同一来源生成炮塔布局、材质和正确开火点 |
| 移除炮塔插件再导出 | 源配置可打开；普通外形保留，无炮塔硬引用；武器降级状态准确 |
| 红绿队伍同时转炮塔 | TeamIndex与炮塔Style不冲突，WPO保留 |
| 车体旋转、坡面、俯仰、后坐 | 投射物发射位置与枪口Burst使用同一有效姿态 |
| 多次导出与组件改名 | 稳定ID不失效，不重复追加特效，不复制玩法配置 |
| Attached枪口效果 | 真正消费原批处理跟随通路；不支持时返回明确失败 |
| 未安装/不兼容提供者 | 原始扩展配置保留，基础导出与无关功能可用 |
| 游戏打包时不带MCP | 普通生成资产可运行；带炮塔产物仅声明相应运行时依赖 |
| 版本矩阵 | UE5.6/5.7/5.8 × 普通版/Net独立编译、导出、运行；不是共用同一DLL |

当前已验证的历史代码不代替新模块的矩阵。Net缺失BakeMassBattleVAT、5.8专属Clear/MassCore依赖先纳入兼容清单。MassBattleFrame源码只读，涉及补齐框架公共能力时单独说明并取得授权。

## 本轮完成定义

交付本目录方案后，实施范围为：MCP源码Actor及协议 → 普通导出 → 可选炮塔 → 炮口Burst绑定 → 原生自动TeamMask → 版本及卸载回归。Attached具体挂点支持以既有后端检查为准，不能混入“已完成”的承诺。其他业务插件之间的解耦、独立运行完整性与Fab发布属于后续任务。
